# LOVABLE MASTER PROMPT 1: DESIGN SYSTEM & EDITORIAL SPECIFICATION

Copy-paste this prompt into Lovable when initializing or redesigning the project visual system.

---

```markdown
Act as a world-class UI/UX designer and design system architect specializing in high-fashion editorial web design and interactive publishing, heavily inspired by KEPLER Interactive (kepler-interactive.com).

I am building a prestigious six-course academic university portfolio.

### 1. CORE DESIGN PRINCIPLES
- Replace all generic "dashboard card" layouts with an editorial, Swiss-inspired print magazine layout translated to the web.
- Alternate sections rhythmically between high-contrast surfaces:
  1. True Black (#171717) for cinematic hero and project showcases.
  2. Pure White (#FFFFFF) for broadsheet academic overviews and resource libraries.
  3. Dark Charcoal (#242424) for pedagogical lecture chronicles and Bloom's outcome matrices.
  4. Off-White (#F7F7F5) for evaluation grids and assignment problem sets.
- Generous whitespace, asymmetric multi-column layouts, thin hairline rules (1px borders in #E2E6E6 for light and #2A2A2A for dark).

### 2. COLOR PALETTE (STRICT TOKENS)
- Orange: #FF8900 (Use exclusively for buttons, active state indicators, hover highlights, and small status pills)
- Charcoal: #242424 (Dominant surface tone for dark sections)
- Black: #171717 (Cinematic backdrop for hero, footers, and code blocks)
- White: #FFFFFF (Pristine paper background for reading-heavy spreads)
- Off-white: #F7F7F5 (Tactile paper card surface)
- Light grey: #E8ECEC (Subtle borders on light backgrounds)
- Muted grey: #929292 (Metadata labels, monospaced captions, and secondary copy)
- Do NOT introduce generic blues, purples, or neon gradients.

### 3. TYPOGRAPHY SYSTEM
- Display Headlines: 'Playfair Display' or 'Instrument Serif' (high-contrast, elegant editorial serif).
- Structural UI & Body: 'Plus Jakarta Sans' or 'Inter' (clean grotesque sans-serif with high readability).
- Metadata & Code Badges: 'JetBrains Mono' (monospaced uppercase, tracking-widest, e.g. "01 // DS-401").

### 4. KEY UI COMPONENTS
- Header: Fixed glassmorphic dark bar with minimalist monotype brand mark, active section navigation, and solid orange Admin CTA.
- Hero: Cinematic black canvas with oversized serif display headline, editorial pull quote, asymmetric course metrics column, and quick-jump ticker.
- Course Switcher Strip: A tactile broadsheet tab strip allowing instant switching across the 6 academic courses:
  1. Data Science (DS-401)
  2. Artificial Intelligence (AI-402)
  3. Advanced Artificial Intelligence (AAI-501)
  4. Fundamentals of Cloud Computing (CC-303)
  5. Entrepreneurship (ENT-305)
  6. Internship Evaluation 1 (INT-490)
```
